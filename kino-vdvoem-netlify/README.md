# Кино вдвоём — Netlify

Комната для двух зрителей с чатом и синхронизацией прямых видеофайлов. Состояние комнаты хранится в Netlify Blobs, отдельная база и ключи не нужны.

## Публикация

1. Загрузите **всё содержимое этой папки** в корень нового репозитория GitHub. В корне должны быть `package.json`, `netlify.toml`, `public/` и `netlify/`.
2. В Netlify выберите **Add new project → Import an existing project → GitHub** и укажите репозиторий.
3. Настройки сборки определяются файлом `netlify.toml`: Publish directory — `public`, Functions directory — `netlify/functions`. Команду сборки оставьте пустой. Нажмите **Deploy**.
4. Откройте адрес `*.netlify.app`, введите имя, затем нажмите **Пригласить друга** и отправьте ссылку второму зрителю.

Netlify установит зависимость `@netlify/blobs` из `package.json`; `.nvmrc` задаёт нужную версию Node.js. Если GitHub показывает только отдельные файлы, проверьте, что файлы в папках `public` и `netlify/functions` тоже загружены.


## Голосовой чат через TURN

Если оба участника вошли в звонок, но видят «Не удалось найти сетевой путь», их сети не пропускают прямое соединение. [Metered Open Relay](https://www.metered.ca/tools/openrelay/) предоставляет 20 ГБ TURN-трафика в месяц без банковской карты:

1. Создайте бесплатный аккаунт Metered и приложение. В адресе приложения вида `https://myapp.metered.live` запомните только `myapp`. В панели найдите API key для TURN credentials (не publishable key для Realtime Messaging).
2. В Netlify нового сайта откройте **Project configuration → Environment variables** и добавьте `METERED_TURN_APP` = имя приложения (например, `myapp`), `METERED_TURN_API_KEY` = его TURN API key. Для ключа включите **Contains secret values**. Не публикуйте ключ в GitHub или чате.
3. Запустите новый production deploy. Затем оба зрителя обновляют комнату и входят в голосовой чат заново.

Сервер запрашивает TURN-доступ только для вошедшего в звонок участника и не отправляет постоянный API key в браузер. Если Metered не настроен, сайт может использовать ранее настроенный Cloudflare TURN через `CLOUDFLARE_TURN_KEY_ID` и `CLOUDFLARE_TURN_API_TOKEN`; без обоих сервисов остаётся прямая связь. Если заданы оба, используется Metered. Проверьте текущие лимиты бесплатного плана у провайдера перед использованием.


## Два профиля и общая библиотека

Профили необязательны для просмотра, но сохраняют оценки в общей библиотеке пары между комнатами. Сначала владелец сайта задаёт в **Netlify → Project configuration → Environment variables** переменную `PAIR_SETUP_CODE` — случайный код длиной не менее 16 символов, помеченный **Contains secret values** и доступный Functions. После этого нужен новый production deploy. Не помещайте код в GitHub и не отправляйте в чат.

Первый зритель открывает «Наша библиотека» в комнате, создаёт профиль по имени, паролю и коду создания пары. Сайт покажет одноразовый код приглашения для второго профиля; передайте его партнёру лично. Второй создаёт свой профиль с этим кодом. Если приглашение потеряно до регистрации второго, первый профиль может выпустить новый код. Регистрация закрывается после двух профилей.

Вход использует защищённую cookie сессии; пароли хранятся в виде хеша. Оценка сохраняется в общей библиотеке после оценки фильма в комнате, если зритель вошёл в свой профиль. Ранее оценённые фильмы остаются в истории старой комнаты, но не добавляются автоматически в библиотеку аккаунтов. При переезде на VPS данные из Netlify Blobs нужно отдельно экспортировать и перенести.

## Как работает просмотр

Ссылка на прямой `.mp4`, `.webm` или `.ogg` синхронизирует паузу и позицию. Внешняя страница открывается внутри комнаты, только когда сам сайт позволяет встраивание; её плеером сайт управлять не может. При запрете встраивания используйте ссылку **Открыть отдельно** и общайтесь в чате комнаты.

Первый вошедший в комнату становится владельцем и выбирает источник для обоих. Ссылки на отдельные видео RUTUBE открываются через официальный встроенный плеер. Для зарубежных платформ HTTP/HTTPS-прокси `host:port` нужно настроить в браузере или системе **у каждого зрителя**: веб-страница не может назначить такой прокси для iframe. Прокси также не отменяет запрет платформы на встраивание.

`npm test` проверяет серверную логику без доступа к Netlify. Комнаты доступны любому, кто знает ссылку; ссылка содержит случайный 128-битный идентификатор. История чата ограничена 80 последними сообщениями. При одновременной активной записи функция может попросить повторить действие.
